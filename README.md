# Tractian Frontend Challenge

This project is an implementation of the Tractian Frontend Engineer Challenge.  
It displays a company asset tree with expand/collapse functionality and shows details for the selected component.

## What I Would Improve

* Add small UI/UX features such as tooltips and user-friendly error handling.
* Centralize tree building, sorting, and filtering logic into a single custom hook.
* Support URL query parameters for selection state, so users can share links directly to a specific node or detail view.
